# ACE

L'app di famiglia di Lani: compiti, studio, organizzazione della sera e un percorso a livelli, **Astra**, che sale dalla terra alle stelle da novembre a giugno. *Per aspera ad astra.* Ogni giorno, passino passino.

Uso solo familiare. Repository privato.

## Cosa c'è qui

| Percorso | Contenuto |
|---|---|
| `CLAUDE.md` | Istruzioni per Claude Code |
| `docs/` | Progetto, regole di gioco, schermate, dati e integrazioni, copione, piano dello sprint 1, installazione |
| `data/config-gioco.json` | Tutti i numeri del gioco (passi, tappe, chiavi, limiti) |
| `data/manifest.json` | Catalogo di avatar, oggetti e sfondi |
| `data/mappa-libri.json` | Indici dei libri di seconda e inventario dei volumi |
| `src/lib/regole/` | Regole di gioco in TypeScript, con test |
| `supabase/migrations/` | Schema del database con le regole di accesso |
| `public/assets/` | 67 avatar, 20 oggetti, 5 sfondi in WebP |
| `design/` | Bozze delle schermate esportate dal canvas di design |
| `scripts/simula_passi.py` | Simulazione del percorso per la taratura |
